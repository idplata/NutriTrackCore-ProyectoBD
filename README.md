# NutriTrackCore-ProyectoBD - Entrega 1
NutriTrack Core es un sistema de base de datos nutricional que estima gramos usando referencias visuales ( un objeto o una parte del cuerpo), calcula IMC y ajusta o recomienda rutinas de ejercicio personalizadas, teniendo en cuenta condiciones médicas si el usuario las presenta, como la diabetes, problemas de tiroides o sobrepeso.
